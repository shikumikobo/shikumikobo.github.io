Excel を何人かで使うと、上書きされる・壊れる。共有の工夫と、WEB アプリに移す目安

2026-11-11　｜　Excel の限界と WEB 化

Excel のファイルを、何人かで使い始めたら、こんなことが起きていませんか。

  • ほかの人が開いていて、自分は「読み取り専用」でしか開けない
  • 保存したら、ほかの人が直した内容が消えていた
  • 「最新版」がどれかわからない。ファイル名に日付と「最終」「最終2」が並んでいる
  • 見せたくない列を隠したが、本当に見られていないか不安

この記事では、起きる理由と、Excel のまま続けられる範囲、WEB アプリに移す目安を整理します。

なぜ起きるのか

Excel のファイルは、もともと1人が1つのファイルを開いて使う前提で作られています。人が増えると、次のことが起きます。

1. 同じファイルの「別の版」が増える

メールやチャットでファイルを回すと、受け取った人が手元で直し、別の名前で保存します。気づくと、同じ表の違う版が、何人分もできています。どれが正しいか、決める方法がありません。

2. 共有フォルダに置くと、同時には直せない

共有フォルダに置いたファイルは、1人が開いているあいだ、ほかの人は読み取り専用でしか開けないことがあります。待つのが面倒で、コピーして別に直す。そこから、上の1番に戻ります。

3. 同時に直すと、後から保存した内容が残る

同時に直せる設定にしても、同じ場所を2人が直すと、あとから保存した人の内容だけが残ることがあります。直したはずの内容が消えても、だれも気づきません。

4. 見せたい人と、見せたくない人を分けられない

シートの非表示や保護は、間違って触らないための目隠しです。見せないことの保証にはなりません。ファイルを渡した人には、中身が渡ったものと考えておくほうが安全です。

Excel のまま続けられる範囲

次のようなときは、Excel のままでも、運用の工夫で続けられます。

  • 書き込む人は1人で、ほかの人は見るだけ。見る人には、PDF や、読み取り専用のファイルを渡す
  • 書く人は何人かいるが、同時には書かない。書く担当や順番を決める
  • Microsoft 365 などの共同編集を使い、1つのファイルを、全員が同じ場所で開く。版が増えるのを防げる

この範囲なら、仕組みを作り替えるより、ルールを決めるほうが、安く済みます。

WEB アプリに移す目安

次のうち、2つ以上あてはまったら、WEB アプリを考える目安になります。

  • 同時に何人もが書き込み、書き換えが重なる
  • 「だれが、いつ、何を直したか」を、あとから見たい
  • 人によって、見せる範囲を分けたい（職人には金額を見せない、お客さんには自分の現場だけ、など）
  • 同じ時間に2人が予約を入れるような、重なりを確実に防ぎたい
  • 外出先のスマホから、入力したい

見本でやっていること

実績のページに、WEB アプリの見本が2つあります（データは、どちらも架空です）。

現場管理アプリ（工務店）

入る人によって、見え方が変わります。職人には担当の現場だけが見えて、金額は見えません。お客さんには、許可された現場の進み具合と、共有されたファイルだけが見えます。

大事なのは、「だれが何を見られるか」を、画面ではなく、データベースの側で守っていることです。画面で隠すだけだと、ブラウザの機能で中身を見られてしまうことがあります。データベースが返さなければ、画面にも届きません。変更の履歴（だれが・いつ・何を）も残ります。

予約と顧客管理アプリ（サロン・教室）

同じ担当者の時間の重なりや、教室の定員を、データベースの側で守っています。2人が同時に同じ枠を押しても、片方しか入りません。予約の変更は、新しい枠を先に取ってから、元の予約を空けるので、変更に失敗しても、元の予約は残ります。

移すときの考え方

WEB アプリに移すと決めても、全部を一度に移す必要はありません。まず、いちばん困っている部分だけを移します。たとえば、予約だけ、現場の進み具合だけです。ほかの Excel の集計や書類づくりは、そのまま使い続けられます。

Excel を使い続けたい会社に向けた、Excel のまま自動にする方法もあります。どちらがよいかは、人数・件数・見せる範囲によります。
